# JalebiSettings

Paper 1.21.9+ (Dialog API) plugin for Jalebi SMP.

- `/settings` – Settings dialog: **Privacy** (TPA / TPAHERE / payments: ANYONE or NO ONE) and **Chat** (public chat / private messages: ON or OFF)
- `/ping [player]` – shows a player's ping
- `/kill` – kill yourself (must type it twice, no player names allowed)

Build: push to GitHub, open Actions, download the `JalebiSettings` artifact.
